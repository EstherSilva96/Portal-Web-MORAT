# 🎸 Morat World | Portal Musical

## 📌 Descripción del proyecto

**Morat World** es un portal web temático dedicado a Morat, una banda colombiana de pop latino. El proyecto tiene como objetivo ofrecer a los fans un espacio donde puedan explorar canciones, consultar portadas de álbumes y acceder a enlaces para escuchar música.

Este sitio web fue desarrollado como parte de la asignatura **Diseño de Sistemas de Internet**, con el propósito de poner en práctica el desarrollo de páginas web y el consumo de servicios web públicos mediante una API.

## 🚀 Funcionalidades

- Página de inicio con diseño temático inspirado en la música de Morat.
- Sección informativa sobre la banda.
- Buscador de canciones.
- Visualización dinámica de títulos, artistas, álbumes y portadas.
- Reproducción de fragmentos musicales cuando están disponibles.
- Enlaces para consultar canciones en Apple Music.
- Diseño adaptable a diferentes tamaños de pantalla.
- Manejo de errores durante las consultas a la API.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura del portal.
- **CSS3:** estilos, colores, tarjetas y diseño adaptable.
- **JavaScript:** interactividad y procesamiento de datos.
- **iTunes Search API:** servicio web público para consultar información musical.
- **Fetch API:** realización de solicitudes HTTP.
- **JSON:** formato de intercambio de datos recibidos desde el servicio web.

## 🔗 API utilizada

Se utiliza la iTunes Search API de Apple para buscar canciones relacionadas con Morat.

Ejemplo de consulta:

https://itunes.apple.com/search?term=Morat&entity=song&limit=12&country=US

Documentación oficial:

https://performance-partners.apple.com/resources/documentation/itunes-store-web-service-search-api/

## ▶️ Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo `index.html` con la extensión Live Server.
4. Navega hasta la sección de canciones.
5. Utiliza el buscador para consultar música de Morat.

**Requisito:** contar con conexión a Internet para consultar la API y cargar las imágenes y los recursos externos.

## 🎓 Propósito académico

Este proyecto permite demostrar conocimientos básicos de desarrollo frontend, consumo de APIs públicas, solicitudes HTTP mediante `fetch()`, procesamiento de respuestas JSON y manipulación dinámica del DOM con JavaScript.
